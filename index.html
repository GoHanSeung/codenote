ABOUT · 이 노트는

CODE NOTE

코드(CODE)를 직접 써보며 정리하는 노트(NOTE).
개념을 읽고 끝나는 강의가 아니라, 개념을 익히는 웹페이지 언어 기초 학습 노트입니다.

📎

로고의 의미

노트를 집는 집게(클립) 모양입니다. 살짝 기울어진 클립이 공책에 끼운 것처럼 보이도록 그려, '필기·기록'이라는 정체성을 한눈에 전합니다.

✏️

이름의 의미

CODE(코드) + NOTE(노트). 보기만 하는 자료가 아니라 직접 써보는 코딩 학습 노트라는 뜻을 담았습니다.

📒

디자인 컨셉

줄선 종이, 손글씨 글씨체, 마스킹 테이프로 붙인 카드, 떠다니는 메모장 등 '공책에 필기하듯'
따뜻한 페이퍼 감성으로 통일했습니다.

WHY · 기획 의도

왜 이 노트를 만들었을까요?

한 학기가 지나고 나면 배운 것이 금방 잊혀지는 경험, 다들 있지 않으신가요?
그 고민에서 이 노트가 시작됐습니다.

01

배운 내용이 금방 잊혀진다

한 학기가 지나면 공들여 배운 내용이 잊혀집니다. → 인터넷과 웹 기초에서 배운 핵심을
언제든 다시 볼 수 있도록 정리했습니다.

02

VS Code 없이도 연습하고 싶다

VS Code가 없는 환경에서는 코드 연습이 어렵습니다. → 시험 기간이나 외출 중에도 휴대폰·태블릿 브라우저만으로 HTML·CSS·JS를 바로 써볼 수 있도록 했습니다.

03

나만이 아닌, 모두를 위해

이 노트가 혼자만의 복습 도구로 끝나지 않으면 좋겠다고 생각했습니다. → 같은 수업을 듣는 수강생분들과 HTML을 처음 접하는 분들에게도 작은 도움이 되길 바랍니다.
